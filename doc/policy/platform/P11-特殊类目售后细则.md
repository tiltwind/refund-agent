# 星辰优选特殊类目售后细则

> 本细则规定各类目在通用政策之上的差异化标准。**与 [P02] 冲突的，以 [P02] 为准**；本细则只作补充，不作减损。

## 第一条 生鲜食品

### 1.1 退款限制

**不支持任何形式的退款申请通过自动通道**，含无理由退货与质量问题。

### 1.2 签收时验货

生鲜商品实行**签收时验货**制度。消费者应在签收时当场查验，发现变质、腐坏、缺斤少两的，当场拍照留证并拒收或立即申请售后。

### 1.3 质量问题的补偿

签收后 **24 小时**内提出质量问题诉求并提供有效凭证的，经核实按下列方式补偿：

| 情形 | 补偿方式 |
|---|---|
| 整批变质、腐坏 | 全额退款 |
| 部分变质 | 按变质比例退款 |
| 缺斤少两 | 按差额退款 |
| 品种、规格错发 | 全额退款或补发 |
| 冷链断链导致品质下降 | 全额退款 |

### 1.4 有效凭证

有效凭证指：**签收当日拍摄的商品照片或视频**，须能看清商品状态、包装、快递面单。超过 24 小时提出且无签收时凭证的，不予受理。

### 1.5 商品无需退回

生鲜商品的质量问题补偿**不要求消费者退回商品**，由消费者自行处置。

## 第二条 定制商品

### 2.1 退款限制

按消费者提供的尺寸、图案、文字、配置单独制作的商品，**不支持无理由退货**。

### 2.2 生产前可取消

商家开始生产前，消费者可无条件取消订单并全额退款。商家应在接单后 **24 小时**内告知预计开工时间。

### 2.3 与约定规格不符

定制成品与消费者确认的稿件、尺寸、材质不符的，属商家违约：

| 情形 | 处理 |
|---|---|
| 完全不符（做错款式、尺寸严重偏差） | 全额退款或重做 |
| 局部偏差（可修改） | 免费返工，或折价补偿后保留 |
| 工艺瑕疵（明显毛边、色差超标） | 返工、重做或折价补偿 |
| 交付逾期超过约定时间 | 消费者可取消并全额退款 |

### 2.4 稿件确认

消费者确认生产稿件后，因个人审美变化提出的修改与退货诉求不予支持。**稿件确认记录由商家保存并在争议中举证。**

## 第三条 虚拟商品

### 3.1 退款限制

充值卡、会员权益、卡券码、点卡、激活码等虚拟商品，**交付即完成核销，不支持退款**。

### 3.2 未核销可退

卡密已发放但**尚未使用、未激活、未核销**的，且在购买后 **24 小时**内申请的，可申请退款。平台核实未核销状态后作废卡密并退款。

### 3.3 交付异常的处理

| 情形 | 处理 |
|---|---|
| 卡密无效、无法激活 | 全额退款或重新发放 |
| 卡密已被他人使用（非消费者过错） | 全额退款或重新发放 |
| 重复购买、重复发放 | 退还多付款项 |
| 充值到错误账号（因平台或商家原因） | 更正或退款 |
| 充值到错误账号（消费者填错） | 协助追回，不保证成功 |

### 3.4 自动续费服务

3.4.1 平台在消费者**接受服务前**及**每次自动续费日期前**以显著方式提醒。

3.4.2 消费者可随时在账户设置中取消自动续费，取消操作**不设置额外障碍**。

3.4.3 已扣费但服务周期尚未开始的，可全额退款；服务已开始的，按未使用天数比例退款。

3.4.4 **平台未履行续费提醒义务的，消费者可要求全额退还该期费用。**

## 第四条 数码与家用电器

### 4.1 无理由退货

未激活、未拆封的数码产品适用通用的无理由退货规则。**已激活的商品视为不完好**，不支持无理由退货（见 [P05] 第 3.2 条）。

### 4.2 三包服务

列入国家三包目录的商品，在通用售后之上另享三包服务：

| 时间节点（自开票之日起） | 消费者可主张 |
|---|---|
| **7 日内**发生性能故障 | 退货、换货或修理（三选一） |
| **8 至 15 日内**发生性能故障 | 换货或修理 |
| 三包有效期内 | 免费修理 |
| 三包有效期内**修理两次仍不能正常使用** | 换货或退货 |
| 送修超过 **90 日**未修好（无零配件） | 换货 |
| 因修理方原因修理超过 **30 日** | 换货 |

### 4.3 三包有效期的计算

三包有效期**自开具发票之日起计算**，扣除因修理占用和无零配件待修的时间。**换货后的三包有效期自换货之日起重新计算。**

### 4.4 三包退货的折旧

符合换货条件但消费者要求退货的，对已使用过的商品可收取折旧费。折旧费自开票之日计算至退货之日，扣除修理占用与待修时间。

> 这与无理由退货「按实付金额全额退还」不同——三包退货可扣折旧。

### 4.5 不实行三包的情形

（一）消费者因使用、维护、保管不当造成损坏的；
（二）非承担三包修理者拆动造成损坏的；
（三）无三包凭证及有效发票的；
（四）三包凭证型号与修理产品型号不符或者涂改的；
（五）因不可抗力造成损坏的。

上述情形不实行三包，但可实行收费修理。

### 4.6 需安装的商品

需另行安装的商品（空调、热水器、大家电），**售后有效期自安装完成之日起计算**，不是签收日。

## 第五条 服装、鞋帽、箱包

### 5.1 无理由退货

适用通用规则。以下情形视为不完好，不支持无理由退货：

- 吊牌被剪、商标标识被摘；
- 有穿着、洗涤痕迹；
- 沾染化妆品、香水、汗渍、宠物毛发；
- 鞋底有户外穿着痕迹。

### 5.2 试穿的界限

**室内试穿、不影响商品原有品质与外观的，不视为已使用**，仍支持无理由退货。

### 5.3 色差与尺码

- 因显示器差异产生的轻微色差不属于质量问题，按无理由退货处理；
- 实物与页面标注尺码表偏差超过标注公差的，属质量问题。

---

## 第六条 食品、保健食品、化妆品

### 6.1 密封包装

**必要的一次性密封包装被损坏的，视为不完好**，不支持无理由退货。

### 6.2 保质期

| 情形 | 处理 |
|---|---|
| 签收时已过保质期 | 全额退款，并按食品安全相关规定赔付 |
| 剩余保质期不足商品页面承诺的 | 全额退款 |
| 临期专区商品（已明示并确认） | 不支持无理由退货 |

### 6.3 食品安全问题

发现异物、变质、胀袋、发霉的，**保留实物与包装**，全额退款并可另行主张赔偿。此类诉求转专项处理。

---

## 第七条 图书、音像与知识付费

7.1 已拆封的音像制品、计算机软件等数字化商品，**法定不适用无理由退货**。

7.2 未拆封的图书、音像制品适用通用无理由退货规则。

7.3 图书出现书写、划线、折页、水渍的，视为不完好。

7.4 在线课程、电子书自购买后**未开始学习/阅读**且在 7 日内申请的，可退款；已开始的按实际进度扣减。

---

## 第八条 珠宝、贵金属与奢侈品

8.1 此类商品价值高、易被调包，退货须经**专业鉴定**。

8.2 消费者申请退货的，商品须保持原包装、证书、防伪标识、封签完整。**封签破坏的不支持无理由退货。**

8.3 退回商品经鉴定与出库时不一致的，平台按 [P08] 的异常退款规则处理。

8.4 鉴定期不计入退款处理时限，但平台须在 3 个工作日内启动鉴定。
